Frequently Asked Questions

❓ Is it safe to download? ▼

Yes! The extension is open-source and you can verify the code on GitHub. It runs entirely in your browser and doesn't require admin permissions.

❓ Do I need to install it every time? ▼

No! Once installed, it stays in Chrome. Future updates can be downloaded and loaded the same way, or enable auto-updates in Chrome settings.

❓ What if I get a security warning? ▼

Chrome shows a warning for any unpacked extension. This is normal and safe. If you're uncomfortable, you can inspect the source code on our GitHub repository.

❓ Can I share this with others? ▼

Absolutely! Share the ZIP file or this download page link with anyone who wants to use Cosmos AI.

❓ How do I uninstall? ▼

Go to chrome://extensions/, find Cosmos AI, and click the Remove button.

❓ Need help with installation? ▼

Check our detailed Installation Guide or open an issue on GitHub.
