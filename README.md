# 🚀 Cosmos AI

**Cosmos** is a privacy-preserving, browser-native multi-agent AI framework for web automation.

It combines a **Thinker (planning)** and **Navigator (execution)** architecture to automate complex web tasks efficiently using Large Language Models (LLMs).

## 🧠 Key Features

- 🤖 Multi-Agent System (Thinker + Navigator)
- 🔐 Privacy-first (runs in browser, no data leakage)
- 💸 Cost-efficient (BYOK model)
- ⚡ Supports multiple LLMs:
  - OpenAI (GPT-4o)
  - Anthropic Claude
  - Google Gemini
  - Groq
  - Ollama (local models)

## 🏗️ Architecture

Cosmos follows a layered architecture:

- Presentation Layer (React UI)
- Service Layer (Background Worker)
- Business Logic Layer (Multi-Agent Engine)
- Integration Layer (LLM Router + DOM Adapter)
- Data Layer (Browser APIs)
